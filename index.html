AI & GPU Infrastructure

A region-pinned inference platform for the token economy.

Engineering teams running high-throughput AI models face opaque multi-cloud routing, disjointed billing contracts, and unpredictable regional latencies. ClusterBid unifies the gateway, console, metering, and reconciliation into a single deterministic deployment.

  • Region-aware infrastructure routing with production deployment verification
  • Real-time token metering and automated billing reconciliation
  • Unified Go workspace modules with strict Next.js console contracts
How it is built (Platform Architecture)

Go workspace services, Next.js console client, Helm overlays, production infrastructure with valid TLS, and automated process-gate tooling.

Visit Website ↗ Technical Overview ↗

Live in production with regional inference routing, token metering, and billing reconciliation available through the platform.

MSME Supply Chain Operations

Bringing operational intelligence to businesses still run on paper.

63 million Indian MSMEs run on WhatsApp messages, paper ledgers, and fragile memory. Generic ERPs fail because they demand foreign workflows. Neev meets operators in their daily rhythm and removes friction where it actually hurts.

  • Order capture and balance reconciliation tailored to textile distribution
  • Strict tenant_id persistence boundaries in a robust modular monolith
  • Operator-in-control AI assistance that reduces typing without removing human judgment
How it is built (Platform Architecture)

Next.js on Postgres-backed monolith, strict tenant_id database invariants, domain models for textile orders and ledgers, and custom process-gate automation.

Visit Website ↗ Technical Overview ↗

First platform version deployed; operator field validation ongoing.

Loyalty Layer for Crypto Cards

The loyalty layer for crypto cards. Enabling unified rewards and global discovery.

Crypto cardholders are fragmented across siloed programs without portable rewards, staking perks, or transparent custody disclosures. Curat unifies the cardholder experience: powering cross-card loyalty, cardholder benefits, and source-checked crypto card discovery.

  • Unified reward and perk infrastructure for modern crypto cardholders
  • Explicit custody status verification: Self-Custody vs Centralized Issuer
  • Global card discovery with automated fee, FX rate, and collateral indexing
How it is built (Platform Architecture)

Kubernetes cluster on Cloud Build CI/CD, Python automated normalization engine, role-based access control, and environment parity between local and production.

Visit Website ↗ Technical Overview ↗

Loyalty infrastructure and source-checked directory; does not constitute financial advice.

Institutional Knowledge Retrieval

A retrieval-augmented generation stack institutions can audit.

When legal teams, universities, or regulators query an AI knowledge system, answers must be mathematically grounded and tenant-isolated. VeriCite enforces boundaries at the retrieval layer rather than relying on brittle post-query filters.

  • Tenant-scoped Qdrant collections with query-time payload security barriers
  • Decoupled transformer pipeline: multilingual embeddings + BGE reranking via HF TEI
  • Ory-powered enterprise identity covering SSO and role hierarchies
How it is built (Platform Architecture)

Hugging Face Text Embeddings Inference (TEI), Qdrant vector database, Ory identity management, monorepo with Kubernetes manifests and Vercel-deployed surfaces.

Retrieval architecture verified in monorepo CI/CD; institutional pilot deployments tailored per security covenant.
